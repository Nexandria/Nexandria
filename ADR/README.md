# Architecture Decision Records (ADRs) - Nexandría

Espacio de registro de decisiones de arquitectura, herramientas y diseño técnico para **Nexandría** (compatible con Obsidian).

## Formato de los Registros

Cada decisión se documenta en un archivo individual bajo la convención `NNNN-titulo-descriptivo.md`, con las siguientes secciones:

- **Título y Metadatos**: Identificador, fecha y estado (`Propuesto`, `Aceptado`, `Reemplazado`).
- **Contexto**: Descripción del problema, restricciones del entorno o librerías y motivaciones.
- **Decisión**: Solución técnica elegida e implementada.
- **Alternativas Evaluadas**: Otras opciones analizadas y razones de descarte.
- **Consecuencias**: Beneficios, impacto y advertencias técnicas o de mantenimiento.
