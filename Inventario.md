# [[Clasificación]]
La clasificación de inventario no solo tiene que ser para reconocer el Ítem, si no que también que dé la opción de Localizar en la biblioteca el título.
El sistema de clasificación, es decir, cada uno de los ítems del inventario; está basado en el sistema Koha.
# [[Crear]] Ítem
Para crear ítem primero se ofrece la opción de escanear el Código de Barras para detectar un elemento que ya está en la sede o en la red. La idea es no repetir información de ejemplares, y tener fuente confiable. Por ello se pregunta si los datos son correctos. Luego intenta buscar información afuera de fuentes confiables como OpenLibrary. Y de última opción crearlo a mano.

Los items se crean de manera masiva, osea que toda la lista de subidos se levanta 1 sola vez. Ahi mismo se genera el archivo imprimible con los nuevos Códigos de Barras.
